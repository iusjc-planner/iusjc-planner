# FE-UX-001 - Coherence UI/ergonomie et design system

Priorite: P2  
Statut: A faire  
Estimation: 3 jours  
Dependances: FE-PAGE-001

## Description

Harmoniser l'experience visuelle /web avec les exigences documentaires (ergonomie, lisibilite, coherence des composants, feedbacks, accessibilite de base).

## Critères d'acceptation

- Design tokens/cohérence couleurs/typo formalises.
- Etats UI uniformes (loading, empty, error).
- Navigation et actions principales intuitives.
- Accessibilite de base respectee (focus, contrastes, labels).

## Taches

- Definir conventions composants.
- Uniformiser headers/tables/forms/modals.
- Ajouter etats UX transverses.
- Revue accessibilite rapide.

## Verification

- Checklist ergonomie validee.
